🎁 Бот розыгрышей — справка

Полное руководство по созданию розыгрышей, каналам, редактуре и аналитике.

Главы: Создание · Каналы · Участие и капча · Редактура · Итоги · Аналитика · FAQ

1. Создание розыгрыша

Меню → 🎁 Создать розыгрыш. Бот проведёт по шагам:

  1. Название — только для вас (в списке «Мои розыгрыши»).
  2. Текст поста — что увидят участники в канале.
  3. Медиа — фото/видео (можно пропустить).
  4. Текст кнопки — например «Участвовать».
  5. Каналы подписки — где участники обязаны быть подписаны (можно без).
  6. Каналы публикации — где выйдет пост (минимум один, бот — админ).
  7. Когда опубликовать — сразу или по времени (формат ДД.ММ.ГГГГ ЧЧ:ММ, МСК; можно просто ЧЧ:ММ — дата подставится). Шаблон копируется кнопкой 📋.
  8. Как подвести итоги — по времени или по числу участников.
  9. Победители — сколько (1–100).
  10. Сообщение победителям — придёт в личку (можно пропустить).
  11. Где итоги — в исходном посте или отдельным постом.
  12. Капча — да/нет.
  13. Предпросмотр — проверка и «Принять».
💡 На каждом шаге есть кнопка-лампочка с краткой подсказкой, «← Назад» и «✖ Отменить». Черновик сохраняется автоматически.

2. Каналы

Если вы админ канала: добавьте бота администратором, затем в боте: Мои каналы → ➕ Добавить канал и отправьте ссылку (@channel), ID канала или перешлите любое сообщение из него.

Если вы НЕ админ: попросите админа канала добавить бота админом, затем перешлите любое сообщение из этого канала боту — канал появится в списке.

⚠️ Бот должен быть администратором в канале — иначе публикация и проверка подписок невозможны.

🔄 Обновить — проверяет админство бота во всех ваших каналах. Каналы, где бот больше не админ, удаляются из списка (передобавьте пересылкой поста). Это безопасно: обновляются только каналы, добавленные вами.

3. Участие и капча

Участник жмёт кнопку «Участвовать (N)» под постом в канале — счётчик участников виден прямо в кнопке, пост закрепляется. Бот проверяет подписки и регистрирует участника.

Если включена капча — откроется окно подтверждения (мини-апп): введите цифры с картинки. Одна попытка на картинку, потом новая.

💡 Победители получают личное сообщение от бота (если задано) и тэгаются в посте с итогами.

4. Редактура

Мои розыгрыши → выберите розыгрыш → ✏ Редактировать. Каждая часть правится отдельно: название, текст, медиа, кнопка, каналы, времена, победители, итоги, капча — без перепрохождения всей цепочки.

У текущих розыгрышей нельзя менять время публикации (пост уже вышел); правки текста/медиа/кнопки сразу обновляют опубликованные посты.

5. Итоги

Розыгрыш завершается по времени или по числу участников. Победители выбираются случайно (взвешенный выбор). Итоги публикуются в исходном посте или отдельным постом — победители кликабельны (тэг). Кнопка под постом меняется на «🏆 Проверить результаты».

Нужен запасной победитель (не отвечает / бот)? Мои розыгрыши → завершённый → 🎲 Доп. победитель.

6. Аналитика

  • По розыгрышу: Мои розыгрыши → розыгрыш → 📊 Аналитика (для текущих — в реальном времени, 🔄 обновляет). Участники, динамика по дням, отток, подозрительный трафик, CSV-выгрузка, удаление накруток.
  • Трекинг-ссылки: Аналитика → 🔗 Создать трекинг-ссылку — UTM-ссылка для замера источника подписчиков.
  • По каналам: Аналитика → 📢 Каналы — клики/подписки/конверсия по каждой UTM-ссылке.

7. FAQ

Время не принимается? Формат: 18:00 или 31.12.2026 18:00. Всё по Москве.

Канал не выбирается? Бот не админ — обновите список или передобавьте бота админом.

Кнопки меню у поля ввода пропали? Отправьте /menu.

Демография (возраст/город)? Недоступна: MAX Bot API не передаёт эти данные участника.
